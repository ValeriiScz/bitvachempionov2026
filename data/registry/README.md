## 1. Что здесь
Два файла: справочник игроков и история ELO по датам снимков. Ключ — ID игрока на mafgame (`mafgame_uid`).
Сайт эти файлы пока не читает — это архив и основа для этапа 2.

## 2. players.csv
Одна строка — один игрок.
Колонки: `mafgame_uid`, `nick` (последний ник), `aliases` (прежние ники), `real_name`, `country`, `club`,
`markery_id`, `markery_nick`, `tournaments` (наши турниры, где был в составе), `last_seen` (дата последнего снимка).
Без `mafgame_uid` строк нет, кроме случаев, когда у игрока не было ID в составе (ключ `nick:`).

## 3. elo_history.csv
Одна строка — игрок × дата снимка. Колонки: `snapshot`, `source`, `mafgame_uid`, `nick`, `markery_id`,
`elo_all`, `place_all`, `tier`, `elo_2026`, `place_2026`, `tournaments_all`, `tournaments_2026`.
«ELO на момент турнира» = строка с ближайшей датой снимка не позже даты турнира.

## 4. Откуда собрано и ограничения
Составы турниров `data/participants_*.json` (снимки markery 25.06–26.10.2026) + леджеры рейтинга mafgame (`data/research/ledger/ledgers.json`, страна).
Места (`place_all`, `place_2026`) есть только в свежих снимках (с 26.10); в старых — только ELO и ранг.
Игроки только из леджеров (топ рейтинга без наших турниров) — без markery_id и без ELO.

## 5. Дальше (этап 2)
Когда markery даст API: робот раз в день дописывает снимок в elo_history.csv, сайт берёт «ELO сейчас» и «ELO на дату» отсюда.
