# data/research/federation — расчёты для федерации MafGame (v1.0 · 2026-11-12)

Выводы — в ваулте: `Мафия/Ресурсы/Форматы турниров и системы баллов — модельные выводы v1.0.md`; PDF для пересылки — там же.

- `rating_variants.py` — рейтинг при других правилах: шкалы баллов (`scales`), отсечка 5–15 (`cutoff`), серийники (`serial`). Запуск из `data/research/model`.
- `format_sim.py` — симулятор турнира (стол 10, роли, победа + доп по силе), калиброван по 53 турнирам MG 2025–26. `mmr_active.json` — MMR активных на 10.11.2026.
- `exp_sizes.py` — размер турнира 30…150; `exp_formats.py N…` — форматы (12+4, 16+4, 20+4, швейцарка, финал 6/8, финал с нуля, полуфиналы, 3 дня, 2 этапа). Запуск из этой папки.
